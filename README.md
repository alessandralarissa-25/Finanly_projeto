# Finanly_controle financeiro para jovens.
O Finanly é um aplicativo desenvolvido com o objetivo de auxiliar jovens na organização e no planejamento financeiro. O sistema permite o controle das entradas e saídas financeiras mensais, contribuindo para uma administração mais equilibrada dos gastos relacionados a lazer, despesas pessoais e investimentos.
